# Owner Capability Policy v2 — Specification 1.0 (2026-11-12)
Owner-approved scope: all 143 Mac Control tools. Operate under macOS user rights and an explicit **task-scoped owner authorization** for actions outside the user's principal work directory. The principal working directory is **AgentWorkspace**, never silently changed.
R01 No hard-coded port, command, process-name, service-log, Git-remote, SSH-key-path, SSH-host-name or Homebrew-formula allowlist that arbitrarily restricts a task already authorized by owner.
R02 AgentWorkspace remains the DEFAULT directory and DEFAULT user-visible guidance, including CLI docs, tool descriptions and project default args. Access outside only if owner explicitly authorizes the particular target/task. No broad persistent root registration is sufficient proof of per-task consent; audit_context alone is NOT authorization.
R03 External access requires a concrete permission in the actual owner request/approved plan for the particular task and target; agent/tool descriptions MUST direct agents to default to AgentWorkspace, never treat audit_context metadata as permission and never use a new root as a permanent blanket approval. Tools must allow explicitly approved external locations within OS privileges, not enforce a hardcoded global root whitelist. A trusted per-task grant could be added later but is not demanded here.
R04 Remote SSH may use any private key accessible to the current OS user and any owner-authorized destination without arbitrary profile/alias pre-registration. Protect private keys; validate hostname and server identity. Previously unknown host keys may be securely onboarded using a first-contact trust step (TOFU) with recorded fingerprint; changed/invalid known keys must fail. Host keys are NOT the client identity keys.
R05 Remove artificial localhost port/path allowlist; retain loopback-only, GET/HEAD, no redirects, bounded bytes/time. DSBridge localhost:8769 works for GET /health and GET /v1/system/status.
R06 Show all process names without six-name filter; generic read-only service log diagnostics, project task support for any task command authorized in scope, preserve existing fixed named shortcuts.
R07 Files/Git/terminal use task-granted roots and owner rights; protect traversal/symlinks and atomic writes/CAS/backup. Git remote not forced to origin; maintain no force-push by default unless task explicitly authorizes. Keep time/size limits or offer streaming.
R08 SSH diagnostics and file transfer support any properly authorized endpoint and identity, with bounded I/O and secure host identification. No command list in ssh_exec; no arbitrary host refusal solely due to absent named profile.
R09 Packages support Homebrew formulas/casks/taps and other native supported installers for authorized tasks, retaining dry-run or explicit mutation classification and bounded process operations.
R10 Browser/GUI/MCP bridge/launchd may operate on supported targets with owner task-scoped consent; retain macOS TCC, OAuth, source provenance, owned sessions, operation identity and prevention of sending to wrong chat. Unsupported methods must be documented, not conflated with permissions.
R11 Preserve Watcher reliability: UNKNOWN never blindly resent, independent Supervisor, ACK separate from approval, immutable SHA256 reports, precise authorization. Existing historical BF33/P06C/ORCH2 content unchanged.
R12 Inventory all 143 public tools, their cross-cutting helpers and alternate registrations; classify remaining restrictions as functional, technical-bound, or security; cite file:line in matrix. Functional restrictions left must be justified and explicitly documented.
R13 Release only after pretest RED/GREEN, staged regression, full GitHub macOS CI success, spec Analyze and Converge, verified rollback backups, publication, one-shot installation on Mac Server and jkmac, live postflight with no Watcher history drift.
Non-goals: disable authentication/TCC, turn off SSH host key verification, exfiltrate credentials, permit external tasks without user-specific grant, bypass a platform/tool refusal.
